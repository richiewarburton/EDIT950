EDIT950 — THIRD-PARTY TOOLS AND SOURCES
=========================================

AKAI Util is bundled as a clearly separate executable and launched as a
subprocess; it is not linked into EDIT950. Its complete corresponding
source accompanies the distributed application. The application otherwise uses
Apple system frameworks and launches a user-selected audio editor only when
that feature is requested. One sanitized, audio-free Ableton
Live user-preset template is included as application data for Drum Rack export;
see section 3.


1. AKAI Util
------------

  S9 samples and P9 programs.

2. User-selected audio editor
-----------------------------

Purpose:
  Optional application used only by the direct S950 sample-editing
  workflow. It must be able to open and save PCM WAV files.

Terms:
  No audio editor is included or required for the rest of EDIT950.
  Users choose and license their preferred editor independently. EDIT950 does
  not link to, redistribute, or depend on a particular editor.


3. Ableton Live user-preset template
------------------------------------

Purpose:
  Used as the structural basis for S950-to-Ableton Drum Rack export. The app
  creates one Ableton Sampler device per exported S950 keygroup.

Provenance:
  Created by the project author in Ableton Live 12.4.3, then sanitized for this
  application. Personal paths, usernames, audio samples, browser identifiers
  and source-preset names were removed. The bundled ADG contains device state
  only and is not the Ableton application or a sound library.

Requirement and terms:
  Ableton Live is proprietary software and is not included. Users must obtain
  and license it from Ableton to open the generated ADG files. Ableton is not
  needed for EDIT950's other features.

Official product site:
  https://www.ableton.com/live/


4. Apple system components
--------------------------

EDIT950 uses SwiftUI, AppKit, AVFoundation, UniformTypeIdentifiers
and CryptoKit supplied with macOS. EDIT950 and its AKAI Util helper
run natively on Apple silicon and Intel Macs; Rosetta is not required.

Gatekeeper and unnotarized-app guidance:
  https://support.apple.com/102445
